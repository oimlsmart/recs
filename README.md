# SMART Recommendations

The published, expert-authored executable OIML Recommendations: the normative
content of the OIML SMART program. This repo serves the component's site at
<https://www.oimlsmart.org/recs>.

A SMART Recommendation renders the normative document as a computable model:
requirements, conformance tests, test report forms, and terminology, each with
clause-level provenance to the source publication. The model is authored in the
Primmel language and published as a versioned package.

Part of OIML SMART. Developed under the OIML SMART program by Ribose.
